# Figures

All figures are stored here. Each generator script is a standalone Python file that uses matplotlib.

## Files

- `fig1_concept.png` — manually drawn concept figure (4 panels: formation/preservation/successful/crossing-fails)
- `fig2_measurement_bias.pdf` / `.png` — generated by `gen_fig2.py`
- `fig3_trajectories.pdf` / `.png` — generated by `gen_fig3.py`
- `fig4_taxonomy.pdf` / `.png` — generated by `gen_fig4.py`
- `fig5_prediction.pdf` / `.png` — generated by `gen_fig5.py`
- `fig6_intervention.pdf` / `.png` — generated by `gen_fig6.py`

## Regenerate

```bash
cd figures
for s in gen_fig*.py; do python3 $s; done
```

## Customize

Each script has style constants at the top (`plt.rcParams.update(...)`). Modify these to change font sizes, colors, etc.

The main parameters to tune per figure:
- `figsize=(width, height)` — figure size in inches
- `plt.bar(width=...)` — bar width
- `linewidth`, `markersize` — line/marker thickness
- `cmap` — colormap for heatmaps
